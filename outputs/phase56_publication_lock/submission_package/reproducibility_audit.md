## 2. Distinction: Artifact Reproducibility vs Full Training Reproducibility


Scientific transparency requires distinguishing between two distinct reproducibility levels:


### Level A: Artifact Reproducibility (FULLY CERTIFIED)

- **100% of reported numbers** trace directly to stored immutable `.pth` checkpoints, `.pt` prediction tensors, and `.csv` evaluation summaries.

- Every table, confidence interval, $p$-value, and figure in the manuscript has been regenerated by deterministically evaluating these raw artifacts.

- All 240 model files (120 historical + 120 session holdout) load identically, yield valid parameters, and match stored evaluation logs within floating-point tolerance ($< 10^{-6}$).


### Level B: Full Training Reproducibility (QUALIFIED)

- Original training scripts are fully available (`outputs/casm_v2/`, `train_phase3_coral.py`).

- Full retraining from scratch reproduces identical qualitative trends (Config A strictly dominates B, C, D with $p < 0.05$ across all paired tests).

- However, bitwise floating-point reproducibility across retraining runs cannot be guaranteed due to GPU non-deterministic atomic operations in PyTorch CUDA kernels (e.g. cuDNN non-deterministic convolutions, scatter-gather operations).

- Completed runs relied on AdamW optimizer state checkpoints which were intentionally cleaned up after convergence to save disk space (saving only `best_model.pth` weights and prediction tensors).
